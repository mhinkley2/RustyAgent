# RustyAgent Feature Planning

RustyAgent is a desktop AI agent chat application built with Tauri 2 + React 19 + TypeScript + Rust.

Inspired by Cursor 3.0, this document tracks the planned feature set for the app.

## Selected Features

1. Multi-Agent Chat UI
2. Agent Tabs / Grid View
3. MCP Integration
4. Local Agent Execution
5. Git Diffs View
6. Integrated Browser / WebView
7. Multiple Model Support
8. Automations (local)
9. Conversation History & Search
10. Streaming Responses
11. Design Mode (UI annotation)
12. PR Management

See child notes for details on each feature.
